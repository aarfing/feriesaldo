# Feriesaldo

Bookmarklet for TV 2 employees: shows your vacation (Ferie and F6) from TOR as days used, days left and use-before dates. It runs in your own browser session; nothing is sent anywhere.

## Install

GitHub does not allow `javascript:` links in READMEs, so it can't be dragged from here. Instead:

1. Create a new bookmark named `Feriesaldo`.
